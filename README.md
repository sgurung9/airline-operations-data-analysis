# airline-operations-data-analysis

**[View Full Project Report](./Airlines_project_report.pdf)**

This project analyzes the relationship between Delta Air Lines' workforce levels, flight cancellations, and financial performance, with particular attention to peak travel seasons. Using operational, employment, and financial data, the analysis explores whether changes in employee headcount and employment type are associated with airline operational performance and financial outcomes.
The project combines multiple aviation datasets to examine trends over time and evaluate whether workforce information can help explain or predict changes in flight cancellations and financial performance.
